Quick Start Guide

Get up and running with DXP AI in under 10 minutes. This guide will walk you through authentication, making your first API call, and rendering content in your application.

1. Install the SDK

# npm
npm install @dxpai/sdk
# yarn
yarn add @dxpai/sdk

2. Initialize the Client

import { DXPAIClient } from '@dxpai/sdk';

const client = new DXPAIClient({
  apiKey: process.env.DXPAI_API_KEY,
  space: 'your-space-id',
});

3. Fetch Content

const content = await client.content.getEntries({
  contentType: 'article',
  personalize: true,
  userId: currentUser.id,
});

// Returns AI-personalized content for this user
